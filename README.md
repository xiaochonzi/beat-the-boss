# 今天又想打老板 · Beat The Boss 3D

基于 Vue 3、TypeScript、Three.js 与 Rapier 的浏览器 3D 卡通物理解压小游戏。所有形象和场景均由程序化几何体生成，无需后端。

## 本地运行

```bash
npm install --registry=https://registry.npmmirror.com
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 底部切换道具；巴掌、键盘、办公椅等点击场景使用。
- 拖鞋、充气锤按住鼠标蓄力，松开发射。
- 默认道具为皮鞭，移动鼠标瞄准后点击甩击。
- 老板使用受控卡通受击动画，不启用动态布娃娃机制。
- 每种道具使用独立程序化 3D 模型与机制：皮鞭甩击、拖鞋旋转投掷、键盘散落键帽、充气锤蓄力挥击、棒球棍横向重击、咸鱼近身拍击。
- 选中的道具会替代游戏区系统光标，以手持 3D 模型持续跟随鼠标；攻击动作从当前手持位置开始。
- 办公椅会从手持位置旋转飞出，命中老板后继续参与场景刚体碰撞。
- 右键拖动旋转镜头，滚轮缩放。
- 解压值达到指定阶段会解锁新道具，100% 后进入 10 秒暴走模式。

设置、成就、最高 Combo 均保存在浏览器 LocalStorage；结算页可生成本地 PNG 分享卡片。
